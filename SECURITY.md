# Security policy

Security fixes target the current default branch. This project does not promise support for older versions or a fixed response time.

## Reporting a vulnerability

Use [GitHub's private vulnerability reporting form](https://github.com/AlbertZheng123/Zeron-Config/security/advisories/new) to report a vulnerability to the maintainer. Do not post live credentials or exploitable details in a public issue.

Include the affected version or commit, reproduction steps, expected impact, and sanitized logs. Revoke any exposed webhook or other credentials through their provider; deleting a value from source does not revoke it.

If private reporting is unavailable, open a public issue asking the maintainer to enable it without including vulnerability details or credentials.
